# Weather Dashboard

A simple Weather Dashboard built with TypeScript and the OpenWeather API.

## Features

- Search weather by city
- Shows temperature
- Shows humidity
- Shows wind speed
- Shows weather icon
- Shows 5-day forecast
- Responsive design

## Technologies

- HTML
- CSS
- TypeScript
- OpenWeather API

## TypeScript

- Strict mode enabled
- Fully typed API responses
- No `any`
- `npx tsc --noEmit` passes
